♥ Custom Projects ♥

Have an idea that doesn't fit into a standard service? I build custom tools and utilities designed around individual workflows, projects, and streaming setups. ♥

Projects are quoted individually based on what you need, how complex it is, and how much development is involved.

What I Can Build

♥ Desktop Utilities ♥

Lightweight desktop applications designed to simplify repetitive tasks or bring several parts of a workflow together into one place.

These can include launchers, configuration tools, status monitors, automation utilities, and other purpose-built applications.

Applications can be packaged for Windows so they can be used without installing Python or development tools.

♥ Stream Automation ♥

Custom utilities designed around an individual streaming setup.

This can include automating startup routines, coordinating streaming applications, controlling overlays, triggering effects, or simplifying a multi-step workflow.

Projects can be designed around tools such as OBS, Streamer.bot, browser sources, local applications, and other software already used in your setup.

♥ OBS & Browser Tools ♥

Custom browser sources, overlays, control panels, alerts, visual effects, and interactive elements designed for use with OBS.

Projects can use manual controls, local data, APIs, or integrations depending on what the project requires.

♥ Workflow Tools ♥

If you have a process that involves repeatedly opening programs, moving between applications, entering information, or performing the same sequence of tasks, there may be a way to make it easier.

Show me the workflow and we can discuss what can realistically be automated or simplified.

How Custom Projects Work

Custom projects begin with a conversation about what you're trying to accomplish.

1. Tell Me the Idea

Explain what you'd like the project to do and, if applicable, show me how you currently handle the task.

2. We Plan It

I'll ask questions about the workflow, features, appearance, platforms, and any software the project needs to interact with.

3. I Provide a Quote

Once the scope is clear, I'll provide an estimated price and development timeline before work begins.

4. Build & Test

I'll develop the project, test its core functionality, and work with you to make sure it fits the workflow it was designed for.

Project Pricing

Custom projects do not use a fixed price.

A small utility may require only a few hours of work, while a more advanced project involving several programs, integrations, devices, or custom systems may require considerably more development.

Pricing is based on the scope, complexity, customization, development time, and testing required.

You'll receive a quote before I begin the project, so you'll know the expected cost ahead of time.

Looking for Something Already Made?

Not every project needs to be built from scratch.

I also keep a catalog of finished tools and projects that can be purchased in their standard form.

If one of those already does what you need, it will usually be simpler and less expensive than commissioning a completely custom version.

Custom Project FAQ

Quick answers about commissioning a custom project.

Do I need to know exactly what I want?

No. A general idea is enough to start. I can ask questions and help turn the idea into a more specific project plan.

Can you modify something you've already made?

Yes. If one of my existing projects is close to what you need, I may be able to use it as a starting point and quote the additional customization separately.

Can you automate my entire streaming setup?

Potentially. It depends on the programs, devices, and services involved.

For larger setups, the best starting point is usually for you to show me the complete workflow so I can determine which steps can realistically be automated.

What if the project becomes larger than expected?

If the requested scope changes significantly during development, I'll discuss the change with you before doing additional work that would affect the price.

Do you provide the finished files?

Yes. Once the project is completed and paid for, you'll receive the files associated with the final project along with any setup instructions or documentation included with it.

Do you provide ongoing updates?

I'm happy to answer reasonable setup questions after delivery.

Larger updates, new features, redesigns, or changes to the original project may require a separate quote.

Discuss a Project

Have something in mind?

Send me a short description of what you want to make, what you want it to accomplish, and any examples or references that might help explain the idea.

For workflow or streaming automation projects, describing how you currently perform the task is especially helpful.
