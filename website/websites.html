How Website Projects Work

I like to understand the project before deciding what it should cost or how long it should take.

1. Tell Me About the Site

Tell me what the website is for, who will use it, and what pages or features you expect it to have.

2. Share Your Style

We can discuss colors, branding, images, layouts, examples you like, and how you want the finished site to feel.

3. Scope & Quote

Once I understand the project, I'll outline the expected scope, price, and estimated completion time before development begins.

4. Development

I'll build the site and test its layout and functionality across different screen sizes.

5. Review

You'll have an opportunity to review the site and request changes covered by the agreed project scope.

6. Handoff

Once the project is complete, you'll receive the finished website files and any documentation or setup information included in the project.

Website Pricing

Website projects are priced individually.

A small personal website with only a few pages requires much less work than a larger business website with many pages, forms, integrations, custom tools, or interactive features.

Pricing is based on the number of pages, complexity of the design, custom functionality, revisions, integrations, and expected development time.

You'll receive a project quote before development begins.

Hosting, Domains & Ownership

The website files themselves are included with the completed project.

Domain names, hosting subscriptions, paid third-party services, and other ongoing external costs remain the responsibility of the client.

If needed, I can help explain how to connect your domain and publish the site.

Once the project has been completed and paid for, the finished website belongs to you. You're free to modify it yourself or have another developer continue working on it later.

Need More Than a Website?

If your idea involves a desktop application, stream automation, a custom utility, or a workflow that goes beyond a normal website, it may fit better under Custom Projects.

Website FAQ

Quick answers about website projects.

How many pages can my website have?

There is no fixed page limit. The number of pages is part of the project scope and affects the final quote.

Will my website work on phones?

Yes. Responsive design is an important part of how I build websites.

The layout is designed to adapt to different screen sizes rather than only working on desktop.

Do you provide hosting?

I provide the website files, but ongoing hosting and domain costs remain the client's responsibility.

I can help guide you through deployment and domain setup when needed.

Can you add forms or booking systems?

Yes, depending on the project.

In some cases I may recommend using an established third-party service rather than building a sensitive or complex backend system from scratch.

Can you update an existing website?

Possibly.

I'll need to review the existing project first so I can determine how it was built and whether I'm comfortable modifying it.

Can I request changes while you're building it?

Yes.

Reasonable revisions that fit within the agreed project scope can be discussed during development.

Significant new features or major changes to the original scope may require an updated quote.

Do I receive the source files?

Yes. Once the website is completed and paid for, you'll receive the finished project files.
